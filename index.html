    Import didn’t work? Paste the page’s code instead

    Many websites block other sites from reading them. You can copy the code yourself:

    1. Open your website in a new tab.
    2. Press Ctrl+U (Windows) or Cmd+Option+U (Mac) to see the page code.
    3. Press Ctrl+A then Ctrl+C (or Cmd on Mac) to copy it all.
    4. Paste it below and click Read code.
